## 1. 核心设计哲学：双轴独立评定

### 1.1 装等 (ilvl) — 控制"数值的深浅"

- **职责**：全权掌管所有属性数值的上限。装备的基础属性、以及每条随机词条的具体数值，全部由 ilvl 缩放。
- **来源**：掉落时由怪物/关卡等级决定；商店出售的固定产品有预设 ilvl。
- **与 Doc 5 的衔接**：Doc 5 定义的 EP 属性价值表直接用于审计物品强度。

### 1.2 稀有度 (颜色) — 评定"潜力的宽窄"

- **职责**：只看这件装备 roll 出了多少条附加词条和技能，与 ilvl 完全无关。
- **核心优势**：ilvl=1 的新手装备 roll 满词条+技能，照样是"橙色传说"。

## 2. 装备部位与槽位映射

结合 Doc 4 已定义的槽位体系：

| 装备部位 | 对应槽位 | 基础属性方向 | 随机词条偏好 |
| :--- | :--- | :--- | :--- |
| **武器** | `WEAPON` | 威力、射程、EN消耗 | 命中率、暴击率、攻击技能 |
| **核心引擎** | `EQUIP` | EN上限、EN回复 | 最大EN、气力获取 |
| **装甲模块** | `EQUIP` | HP加成、装甲值 | 格挡率、招架率、防御技能 |
| **辅助芯片** | `EQUIP` | 无固定方向 | 全随机，补短板或堆极限 |

> **FIXED 槽位**不参与掉落系统——机体自带的专属武装，不受物品系统管辖。

## 3. 词条系统：分档制 (Tiered Affixes)

每件装备最多 **3 个属性词条槽 + 1 个技能槽**。

### 3.1 属性词条档位

每个属性词条槽独立 roll，结果为 T0~T4 五个档位之一：

| 档位 | 含义 | 出现概率 | 数值系数 |
| :--- | :--- | :--- | :--- |
| **T0** | 空槽，没有词条 | 39% | — |
| **T1** | 低档 | 35% | `base + ilvl × scale × 0.70` |
| **T2** | 中档 | 18% | `base + ilvl × scale × 0.85` |
| **T3** | 高档 | 7% | `base + ilvl × scale × 1.00` |
| **T4** | 顶级 | **1%** | `base + ilvl × scale × 1.15` |

> 概率可由怪物类型调整：精英怪可降低 T0 概率（如 25%），BOSS 可进一步降低（如 15%）。

### 3.2 技能槽

| 结果 | 出现概率 |
| :--- | :--- |
| 无技能 | 99.5% |
| 获得技能 | **0.5%** |

技能从 `data/affixes.json` 中 `type = "skill"` 的词条池按权重随机选取，受 `min_ilvl` 门槛限制。

### 3.3 词条配置文件 (`data/affixes.json`)

```json
{
  "stat_hit_rate": {
    "type": "stat",
    "target": "final_hit",
    "base_value": 2.0,
    "ilvl_scale": 0.2,
    "min_ilvl": 1,
    "weight": 1000,
    "slot_tags": ["WEAPON", "EQUIP"]
  },
  "stat_crit_rate": {
    "type": "stat",
    "target": "final_crit",
    "base_value": 1.0,
    "ilvl_scale": 0.1,
    "min_ilvl": 10,
    "weight": 500
  },
  "skill_auto_repair": {
    "type": "skill",
    "skill_id": "auto_repair",
    "min_ilvl": 20,
    "weight": 100
  }
}
```

## 4. 颜色判定

**颜色分 = 已 roll 属性数 + (有技能 ? +2 : 0)**

| 颜色分 | 稀有度 | 达成方式 |
| :--- | :--- | :--- |
| 0 | ⬜ 普通 (白) | 3 个槽全 T0，无技能（商店白板） |
| 1 | 🟩 优秀 (绿) | 1 条属性 |
| 2 | 🟦 精良 (蓝) | 2 条属性 |
| 3 | 🟪 史诗 (紫) | 3 条属性 **或** 1 属性 + 技能 |
| 4+ | 🟧 传说 (橙) | 2 属性 + 技能 **或** 3 属性 + 技能 |

技能因为 +2 的权重，**直接跳两级颜色**，体现技能的极端珍贵。

### 极品概率估算（以普通怪为例）

- 3 属性全 T4 + 技能：`(1%)³ × 0.5% = 0.000005%`（百万分之五）
- 3 属性任意档 + 技能（橙色）：`(61%)³ × 0.5% ≈ 0.11%`（千分之一）
- 3 属性全非零（紫色）：`(61%)³ ≈ 22.7%`

## 5. 掉落生成流程

怪物被击败时：

1. **算 ilvl**：`ilvl = 怪物等级 × 系数 + 随机浮动(±5%)`
2. **选装备模板**：从怪物掉落表按权重选取 `equipment_id`
3. **Roll 3 个属性槽**：
   - 每槽独立 roll T0~T4
   - 非 T0 则从满足 `min_ilvl ≤ ilvl` 的词条池中按 `weight` 选取（已选不重复）
4. **Roll 技能槽**：0.5% 概率出技能，出则按 `weight` 选取
5. **算颜色**：属性数 + (技能×2)

## 6. 商店系统

- **功能**：为掉落"托底"，保证玩家始终有升级路径
- **动态白板**：根据玩家通关进度，出售当前 ilvl 的 **白色基础款**（0 属性、0 技能）
- **设计意图**：高 ilvl 的基础属性本身就很强，脸黑时花金币买白板也能推关

## 7. 数据库存储

### 7.1 UserEquipment.random_stats JSONB

```json
{
  "ilvl": 30,
  "affixes": [
    {"id": "stat_hit_rate", "t": 3},
    {"id": "stat_crit_rate", "t": 1}
  ],
  "skill": "auto_repair"
}
```

- **不存具体数值**——运行时由 `词条配置 + ilvl + 档位` 精确还原
- **不存颜色**——运行时由 `len(affixes) + (skill ? 2 : 0)` 即时计算
- 极度紧凑，每件装备仅几十字节

### 7.2 Pydantic 契约

```python
class AffixEntry(BaseModel):
    id: str       # 词条 ID，关联 affixes.json
    t: int        # 档位 1~4

class EquipmentRandomStats(BaseModel):
    ilvl: int = 0
    affixes: list[AffixEntry] = Field(default_factory=list, max_length=3)
    skill: str | None = None  # 技能 ID 或 None
```

### 7.3 SnapshotFactory 集成

`SnapshotFactory.create_combat_snapshot()` 组装时：
1. 读取 `UserEquipment` 的 `random_stats`
2. 对每条 affix：用 `affixes.json` 的 base/scale + ilvl + 档位系数算出具体数值 → 累加到快照属性
3. 若有 skill：通过 Doc 2 的 `EffectFactory` 创建 `Effect` 并注入 `SkillRegistry`
4. 输出的 `MechaSnapshot` 已包含全部装备加成，战斗引擎完全透明

## 8. 完整示例

**ilvl=30 的光束步枪，击败精英怪掉落：**

```
🟪 光束步枪 [ilvl 30]
   基础威力: 1400
   射程: 1000-6000m
   ─────────────
   ✦ 命中率 +7.0%  (T3)
   ✦ 暴击率 +2.7%  (T1)
   ✧ [空]
   ✧ [无技能]
   颜色分: 2 → 蓝色
```

数据库存储：
```json
{"ilvl": 30, "affixes": [{"id": "stat_hit_rate", "t": 3}, {"id": "stat_crit_rate", "t": 1}], "skill": null}
```

## 9. 后续扩展预留

| 机制 | 说明 | 预留方式 |
| :--- | :--- | :--- |
| **拆解与重铸** | 拆低 ilvl 橙装提取技能，刻到高 ilvl 白板 | `skill` 字段支持直接重写 |
| **强化等级** | `enhancement_level` 提升基础属性倍率 | DB 字段已存在 |
| **套装效果** | 同系列多件装备触发被动技能 | 快照组装时检测并注入 |
| **词条锁定** | 重铸时保护某条词条 | affix 增加 `locked` 标记 |
